These code exercises are designed to strengthen teams that have already been supported. They follow a consolidation approach: revisiting practices introduced during the initial coaching, deepening them through concrete scenarios, and anchoring lasting habits around design quality and craftsmanship.

The program includes 10 TDD exercises, focused on writing tests first, progressing in small steps, and letting a simple and robust design emerge from business scenarios. The goal is to reinforce the Red / Green / Refactor cycle and the clarity of feedback provided by tests.

It also features 5 refactoring exercises, centered on improving existing code without changing its behavior. These exercises help develop code-reading skills, the ability to identify code smells, and the application of safe, incremental transformations to keep the code clean and maintainable.

Finally, 5 dependency-breaking exercises complete the set. Their purpose is to train teams to regain control over code that is hard to test or evolve by progressively isolating dependencies (I/O, frameworks, external services), restoring better design, testability, and decoupling.

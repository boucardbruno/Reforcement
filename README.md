These code exercises are designed to **strengthen teams that have already benefited from coaching**. They follow a **consolidation approach**: revisiting the practices introduced during the initial coaching.

The program also includes **2 refactoring exercises**, focused on improving existing code without changing its behavior. These exercises help develop **code-reading skills**, the ability to **identify code smells**, and the application of **safe, incremental transformations** to keep the code clean and maintainable.

Finally, **2 dependency-breaking exercises** complete the set. Their goal is to train teams to **regain control over code that is difficult to test or evolve**, by progressively isolating dependencies (I/O, frameworks, external services) in order to restore **better design, improved testability, and clearer decoupling**.
